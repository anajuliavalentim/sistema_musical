# 🎧 sistema-musical

## 📌 Sobre o Projeto

Este projeto tem como objetivo desenvolver um catálogo musical inspirado em plataformas como Spotify, Netflix e Goodreads, que organizam criadores e suas respectivas obras.

A proposta é criar um sistema de cadastro e organização de músicas e artistas, utilizando HTML e CSS para desenvolver a interface visual.

## 🎯 Objetivo

Desenvolver o **Front-End** de um sistema de catálogo, trabalhando a estrutura das páginas, a organização dos elementos e a identidade visual do projeto.

Nesta primeira etapa, foram utilizados HTML e CSS puro, sem integração com banco de dados.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Variáveis CSS (`:root`)

## 📂 Estrutura do Projeto

```text
📁 catalogo-musical
 ├── login.html
 ├── index.html
 └── styles.css
```

## ✅ Funcionalidades Desenvolvidas

### 🔐 Tela de Login — `login.html`
- Formulário de login centralizado.
- Utilização de Flexbox para alinhamento dos elementos.
- Campos para entrada de dados.

### 🏠 Página Inicial — `index.html`
- Menu principal do sistema.
- Organização de três cards em formato de grade.
- Utilização de CSS Grid.

### 🎨 Estilização — `styles.css`
- Definição de variáveis de cores utilizando `:root`.
- Estilização de formulários e botões.
- Organização visual das páginas.
- Personalização da identidade visual.

## 🚀 Próximas Etapas

Na Sprint 2, o projeto receberá novas funcionalidades, incluindo:

- Desenvolvimento do Back-End com PHP.
- Integração com banco de dados.
- Cadastro e gerenciamento de artistas.
- Cadastro e gerenciamento de músicas.
- Integração entre Front-End e Back-End.

## 🏆 Desafio da Equipe

Escolher um tema para o catálogo e personalizar a identidade visual do projeto, modificando as cores definidas em `:root` para criar uma paleta própria.
